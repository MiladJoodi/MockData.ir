Inconsistent error payloads force UI branches everywhere. Pick one shape and stick to it across temporary and real APIs.

## Minimal fields

Include `code`, `message`, and optional `details`. That covers toast copy and form field errors.

```json
{
  "code": "validation_error",
  "message": "Email is invalid",
  "details": { "field": "email" }
}
```
