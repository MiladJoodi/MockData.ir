Messy minified JSON slows everyone down. A clean pretty-print makes nesting, arrays, and nulls obvious at a glance.

## Keep keys stable

When you regenerate fixtures, keep key order consistent so diffs stay small and reviews stay focused.

## Validate before you paste

Run a quick parse check in the JSON workbench before dropping payloads into tests or docs.

```json
{
  "ok": true,
  "items": [1, 2, 3]
}
```
