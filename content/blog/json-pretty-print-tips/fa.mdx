JSON فشرده و درهم کار را کند می‌کند. Pretty-print تمیز باعث می‌شود nesting، آرایه‌ها و nullها یک‌نگاه مشخص باشند.

## کلیدها را پایدار نگه دارید

وقتی fixture بازتولید می‌کنید، ترتیب کلیدها را ثابت نگه دارید تا diff کوچک و ریویو ساده‌تر شود.

## قبل از پیست اعتبارسنجی کنید

در JSON Workbench یک parse سریع بزنید، بعد payload را در تست یا مستندات بگذارید.

```json
{
  "ok": true,
  "items": [1, 2, 3]
}
```
