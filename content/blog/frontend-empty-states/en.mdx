Empty screens are easy to forget until staging. Feed the UI mock collections of different sizes early.

## Cover three sizes

Zero rows, a single row, and a long list catch most layout bugs before real data shows up.

## Keep copy short

Empty-state messages should explain the next action in one line—not a paragraph.

MockData generators make those fixtures cheap to rebuild when the schema changes.
