payload خطای ناسازگار UI را پر از شاخه می‌کند. یک شکل انتخاب کنید و در API موقت و واقعی ثابت بمانید.

## فیلدهای حداقلی

`code`، `message` و در صورت نیاز `details` کافی است—هم برای toast و هم خطای فرم.

```json
{
  "code": "validation_error",
  "message": "ایمیل نامعتبر است",
  "details": { "field": "email" }
}
```
